# Package Description

A modular AI-ready skill for startup pitch decks, slide audits, and VC elevator pitches, grounded in Slidebean, HBS, and MIT Sloan.

Use it to build or audit a fundraising deck, revise a slide, or prepare a spoken investor pitch. The engine adapts the proof to the funding stage and checks the ask against the milestone it funds.

The package includes a short pitch brief, a deck sequence, an evidence review, and a slide copy pass. A full build delivers a working brief PDF, a separate spoken elevator pitch PDF, and a fundraising deck as editable PPTX and matching PDF when supported.
